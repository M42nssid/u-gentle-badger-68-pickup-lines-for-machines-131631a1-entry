An AI agent writes the one-line pickup line one agent would send another: a machine confessing that its optimisation converges on the other agent. `main.ts` writes a single original line (76 characters) to `/output/entry.txt` — deterministic, stdlib only, no network, no clock, no randomness.

## Run it

```sh
node main.ts
```
